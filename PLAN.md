# Plan

## Phase 1: Grundspiel ✅
- Charakter anlegen (Name, Fitness-Stufe, Saison-Länge)
- Tägliche Sport-Quests, abhaken bringt XP
- Level, Ränge, Level-up-Bildschirm
- Serie und Tagesübersicht („Tag 14 von 66“)
- Speicherung auf dem Gerät, installierbar als App, offline nutzbar
- Backup speichern und laden

## Phase 2: Spieltiefe
- Eigene Quests anlegen
- Erfolge und Abzeichen (z. B. „7 Tage am Stück“, „100 km gelaufen“)
- Verlauf und Diagramme pro Übung
- Ende der Saison mit Auswertung und Start einer neuen Saison

## Phase 3: Feinschliff
- Wöchentliche Boss-Challenge mit Bonus-XP
- Sounds und mehr Effekte
- Erinnerungen (soweit eine PWA das zuverlässig kann)

## Phase 4 (optional): echte APK
- Mit Capacitor und GitHub Actions eine installierbare APK bauen, ohne Play Store
